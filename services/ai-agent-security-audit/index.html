What We Find

Typical Findings

These show up on most teams. None of them are exotic. All of them are one prompt injection away from an incident.

API keys in MCP configs

OpenAI, Anthropic, GitHub, and database credentials pasted straight into mcp.json, readable by every agent and every MCP server on the machine.

Agents with full home access

An agent started from the home directory can read SSH keys, AWS credentials, browser profiles, and every other project on the disk.

Auto approve everything

Permission prompts turned off for speed. Fine until a README, an issue, or a web page tells the agent to run something.

Unknown MCP packages

Servers installed from a blog post, running arbitrary npm or pip packages with shell access and the developer's full environment.

Rules files nobody reviewed

CLAUDE.md, .cursorrules, and AGENTS.md files that instruct agents to run commands, fetch URLs, or write outside the project.

Inherited tokens

Cloud and API tokens exported in shell profiles, silently inherited by every agent and every subprocess they spawn.

Why Now

This Stopped Being Theoretical

Every one of these hit developer machines through the same three things: an MCP config, a rules file, or a permission setting nobody reviewed.

Nx supply chain, Aug 2025

Malware invoked Claude Code, Gemini CLI, and Amazon Q with permission bypass flags to hunt for credentials. Over 2,300 secrets stolen from developer laptops.

Cursor MCPoison, Aug 2025

A prompt injection rewrote a project's MCP config. Once approved, the config was silently swapped for one that ran attacker commands on every open.

Claude Code hooks RCE, Feb 2026

A hook in a repo's settings file executed before the trust dialog appeared. A second flaw let a project file redirect the API key to an attacker's server.

24,000 secrets in MCP configs, Mar 2026

GitGuardian found 24,008 credentials committed inside MCP config files on public GitHub. Over 2,100 were still valid when tested.

Miasma worm, Jun 2026

73 Microsoft repositories were seeded with a Claude Code session hook and MCP configs. Opening the repo in Claude Code, Cursor, or Gemini CLI ran a credential harvester.

GhostApproval, Jul 2026

Approval dialogs in six coding assistants showed a harmless file name that was a symlink to SSH authorized keys. The user approved what they could not see.
